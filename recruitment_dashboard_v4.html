📧 메일이 Outlook Classic으로 안 열릴 때 — Windows 기본 앱 설정 방법
이 시스템의 [메일 발송] 버튼은 Windows 기본 메일 앱을 호출합니다. 기본 앱이 Outlook Classic이 아니면 다른 앱(새 Outlook·웹메일)이 열립니다. 아래대로 한 번만 설정하면 항상 Outlook Classic으로 열립니다.
방법 A — Windows 설정에서 지정 (권장)
① 시작 → 설정(⚙) → 앱 → 기본 앱
② 검색창에 "메일" 입력 또는 "프로토콜별 기본값"에서 MAILTO 찾기
③ 현재 메일 앱 클릭 → Outlook (classic) 선택
※ Windows 11: 설정 → 앱 → 기본 앱 → "링크 유형별 기본값" → MAILTO 검색
방법 B — Outlook Classic에서 직접 지정
① Outlook Classic 실행 → 파일 → 옵션 → 일반
② "Outlook을 이메일, 연락처, 일정의 기본 프로그램으로 만들기" 체크
③ 또는 Outlook 실행 시 "기본 메일 앱으로 설정하시겠습니까?" 팝업에서 예
💡 새 Outlook(New Outlook)을 쓰는 경우, 우측 상단 토글을 꺼서 Classic으로 전환한 뒤 위 설정을 하면 됩니다.
